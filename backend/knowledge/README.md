# Policy Knowledge Base

Each `.md` file is split on `## ` headings; every section becomes a retrievable passage
used to ground AI drafts and policy auto-answers.

**These files are PLACEHOLDER policies written for the demo.** Before go-live, Beacon's
CX and legal teams must replace them with the approved wording. The engine reloads them
on start-up (or via `POST /api/admin/knowledge/reload`). This README is not indexed.
